Sou estudante de **Engenharia de Software na FIAP** e gosto de transformar problemas reais em soluções através da tecnologia.

Grande parte do meu aprendizado acontece colocando a mão no código: desenvolvendo projetos, investigando problemas, refatorando soluções e buscando entender não apenas **como fazer funcionar**, mas como construir software de forma mais organizada e sustentável.
